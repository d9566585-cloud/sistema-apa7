Análisis de Riesgos

Riesgos Críticos Identificados

Se han identificado cuatro riesgos críticos (evaluación Alta) que requieren atención inmediata:

  • R01 - Fallas tecnológicas: Incompatibilidad de librerías que puede paralizar el desarrollo.
  • R02 - Retrasos en el desarrollo: Subestimación de complejidad que puede incumplir plazos.
  • R05 - Errores de implementación: Fallos lógicos que comprometen la funcionalidad del sistema.
  • R06 - Gestión de cambios ineficaz: Cambios no controlados que desvían el proyecto.

Estrategias de Mitigación

Para cada riesgo se han definido estrategias específicas de tratamiento:

  • Reducir: Implementar pruebas continuas, estimaciones detalladas y entornos estandarizados.
  • Mitigar: Establecer sistemas de control de versiones y copias de seguridad automáticas.
  • Monitorear: Seguimiento constante del cronograma y comunicación efectiva con stakeholders.

Medidas Preventivas Clave

La implementación de GitHub para control de versiones, respaldos automáticos, pruebas exhaustivas y seguimiento del cronograma son fundamentales para el éxito del proyecto.
