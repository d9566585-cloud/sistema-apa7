# Sistema Automatizado APA 7

## Arquitectura de Software - Ingeniería de Software

Este proyecto presenta una simulación de arquitectura de software para un sistema automatizado capaz de analizar y corregir documentos académicos bajo las normas APA 7.

---

# Objetivo

Desarrollar una simulación funcional que represente el flujo de procesamiento y normalización automática de documentos académicos utilizando conceptos de arquitectura de software.

---

# Funcionalidades del Sistema

- Análisis de documentos académicos
- Detección de errores APA 7
- Corrección automática de formato
- Generación de referencias
- Normalización de documentos

---

# Arquitectura Utilizada

El sistema está basado en una arquitectura modular orientada a procesamiento de documentos.

## Flujo principal

```text
Usuario
   ↓
Interfaz Web
   ↓
Carga Documento .docx
   ↓
Analizador APA 7
   ↓
Normalizador APA
   ↓
Generador de Referencias
   ↓
Documento Corregido
```
